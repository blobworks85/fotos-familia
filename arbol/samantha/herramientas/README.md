# Árbol de la familia de Samantha Quiroz Huerta

Página: `arbol/samantha/index.html`, con los datos cifrados (contraseña propia, distinta a la del árbol Fuentes Siller).

Empieza en Samantha y sube por sus padres: lado Quiroz Medina (papá) y lado Huerta Rodríguez (mamá).
Misma plantilla que `arbol/herramientas/`, adaptada para una sola raíz.

Para actualizar: generar `datos.json` desde Notion (misma forma que el árbol Fuentes Siller, con `raices` = [id de Samantha])
y correr `python3 herramientas/build.py datos.json herramientas/plantilla.html index.html CONTRASEÑA`.
**Nunca subir datos.json.**
